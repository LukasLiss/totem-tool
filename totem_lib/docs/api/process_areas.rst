Process areas
=============

Group object types into process areas. ``mlpaDiscovery`` works from a TOTeM
model. ``discover_process_areas`` uses resource indicators computed from the
log instead.

The :doc:`process areas guide <../guide/process_areas>` explains the indicators,
the parameters and both algorithms.
